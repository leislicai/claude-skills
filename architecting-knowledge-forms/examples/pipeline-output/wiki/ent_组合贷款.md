# 组合贷款

## 概述

组合贷款是指借款人在购买自住住房时，住房公积金贷款额度不足以满足购房资金需求，由住房公积金贷款与商业银行个人住房贷款相结合，共同为借款人提供购房资金的贷款模式。组合贷款中，公积金贷款部分由住房公积金管理中心提供，不足部分由商业银行按商业性个人住房贷款政策补充，商贷银行须与住房公积金管理中心签订合作协议。

## 核心标准

### 一、贷款对象与条件

**基本条件：**
- 连续缴存住房公积金**6个月以上**的职工
- 借款人及配偶需**同时满足**公积金中心和商贷银行的各项条件要求
- 具有完全民事行为能力
- 信用良好，有稳定的经济收入和偿还贷款本息的能力
- 提供符合要求的购房合同及相关证明

**共同借款人：**
- 借款人的配偶为自然共同借款人
- 单身或单方缴存职工的直系亲属（父母）可作为共同借款人
- 共同借款人限定为配偶、父母、子女

### 二、贷款额度规则

| 因素 | 公积金贷款部分 | 商业贷款部分 |
|-----|--------------|-------------|
| 最高比例 | 首套最高房总价**70%**，二套最高**60%** | 银行根据自身政策确定 |
| 上限约束 | 受**公积金管理委员会**规定的最高额度约束 | 由银行自行确定，不受公积金上限约束 |
| 二手房价值认定 | 按中心认定价值为准 | 按银行评估价值为准 |
| 月供收入比 | 不超过月收入的**50%-60%** | 银行在扣除公积金月供后计算，合计不超过规定比例 |

**贷款总额 = 住房公积金贷款额度 + 商业银行贷款额度**，合计不超过所购住房总价减去首付款后的余额。

### 三、贷款利率与期限

**利率标准：**
- 公积金贷款部分：按中国人民银行规定的住房公积金贷款利率执行
- 商业贷款部分：按商业银行个人住房贷款利率执行
- 两部分**分别按各自利率标准**执行

**贷款期限：**
- 公积金贷款与商业贷款**期限相同**
- 最长**30年**
- 还款方式限**等额本息**或**等额本金**

### 四、贷款流程

**申请与受理：**
1. 组合贷款楼盘须经中心与银行**双重准入备案**（二手房除外）
2. 借款人及其配偶向中心管理部服务大厅提出申请
3. 由中心和银行分别确认公积金和商业贷款资格

**审批流程：**

```
借款人申请
    ↓
公积金中心与商贷银行分别审批
    ↓
中心先审批 → 确定公积金贷款要素
    ↓
转商贷银行审批 → 银行确认商业贷款要素
    ↓
结果回传中心 → 完善系统信息
```

**贷前调查：**
- 中心和银行分别调查贷款用途、资料真实性、抵押物状况
- 调查借款人还款能力、征信记录、婚姻状况等
- 面谈面签时告知贷款流程，由借款人及配偶填写资料并签合同
- 不允许第三方共同申请

**抵押登记与放款：**
1. 抵押登记由公积金中心与商贷银行**共同申请**，同为**第一顺位抵押权人**
2. 贷款发放分别在抵押登记完成或担保落实后进行
3. 中心和银行各自划拨资金至借款人收款账户

### 五、贷款担保

**一般规则：**
- 能办理房产抵押的优先办理抵押登记
- 暂时不能办理预抵押的，公积金和商业贷款分别按各自规定落实担保
- 待条件具备时共同办理抵押登记

**风险控制：**
- 公积金贷款风险由**中心承担**
- 商业贷款风险由**银行承担**
- 公积金贷款结清前，账户资金只用于偿还公积金贷款
- 公积金贷款结清后可提取偿还商业贷款
- 抵押权利证明分别保管，部分结清后可分别注销抵押登记

### 六、贷款偿还与贷后管理

**还款方式：**
- 借款人按月分别偿还公积金贷款本息和商业贷款本息
- 可提前部分或全部偿还公积金贷款
- 商业贷款提前还款需银行确认公积金还款状态正常后，按银行规定办理

**贷后管理：**
- 中心和银行各自维护借款人信息并催收逾期贷款
- 借款人违约可分别诉讼
- 抵押物处置按贷款余额比例清偿
- 组合贷款档案**分别单独管理**

**逾期处理：**
- 连续3个月以上违约：发放催收通知书
- 连续6个月以上违约：中心有权起诉并强制划转借款人及配偶的公积金用于还款
- 商业贷款部分按银行违约规定处理

## 适用条件

1. **额度不足原则**：组合贷款适用于公积金贷款额度不足以满足购房资金需求的情形，由商业贷款补足差额部分。

2. **双重准入**：所购楼盘须经公积金中心和商贷银行双重准入备案，二手房除外。

3. **同步审批**：公积金贷款与商业贷款分别审批，先中心后银行，资料共享避免重复提交。

4. **抵押物优先**：能办理房产抵押的应优先办理抵押登记，中心和银行同为第一顺位抵押权人。

5. **担保分离**：暂时不能办理预抵押时，公积金和商业贷款分别按各自规定落实担保。

6. **资金独立**：中心和银行各自划拨资金，贷款风险各自承担。

## 相关依据

1. **《住房公积金管理条例》**（国务院令第262号）
   - 第二十六条至第二十七条：贷款申请及担保
   - 第五条：住房公积金用途限制

2. **《天水市住房公积金个人住房贷款管理办法》**
   - 贷款对象和条件（含共同借款人规则）
   - 贷款额度、期限和利率
   - 贷款担保相关规定

3. **天水市住房公积金管理中心与商业银行合作协议**
   - 商贷银行须与中心签订合作协议
   - 明确双方在组合贷款中的权利义务

4. **天水市住房公积金管理中心贷款政策调整通知**
   - 贷款额度倍数调整
   - 首付比例调整
   - 止付金额规定

5. **《天水市住房公积金流动性风险预警管理办法》**
   - 流动性风险管控措施对组合贷款的影响
   - 贷款额度打折、轮候发放等应急机制

6. **相关规程（市内适用）**
   - 组合贷款贷前调查操作细则
   - 组合贷款审批及放款流程操作规程
   - 组合贷款抵押登记共同申请规程
