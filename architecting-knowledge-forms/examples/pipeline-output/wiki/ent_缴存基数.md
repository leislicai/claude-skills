# 缴存基数

- **类型**：clause（条款）
- **所属领域**：住房公积金
- **适用范围**：天水市（依据天水市住房公积金管理中心相关规定）

---

## 一、概述

**缴存基数**是计算住房公积金月缴存额的基础数值，即职工本人上一年度月平均工资，是确定职工个人和所在单位每月应缴存住房公积金金额的核心依据。

根据《住房公积金管理条例》第十六条，职工住房公积金月缴存额和单位为职工缴存的月缴存额，均以职工本人上一年度月平均工资为基数，分别乘以相应的缴存比例计算得出。

缴存基数的确定直接关系到职工住房公积金账户的资金积累水平，是公积金制度的核心要素之一。

---

## 二、核心标准

### 2.1 月缴存额计算公式

职工住房公积金的月缴存额为**职工本人上一年度月平均工资**乘以职工住房公积金缴存比例。单位为职工缴存的住房公积金的月缴存额为**职工本人上一年度月平均工资**乘以单位住房公积金缴存比例。（《条例》第十六条）

> 公式：
> - 职工月缴存额 = 上一年度月平均工资 × 职工缴存比例
> - 单位月缴存额 = 上一年度月平均工资 × 单位缴存比例

### 2.2 新参加工作与新调入职工

- **新参加工作职工**：从参加工作的第二个月开始缴存住房公积金，月缴存额以**职工本人当月工资**为基数。（《条例》第十七条）
- **单位新调入职工**：从调入单位发放工资之日起缴存住房公积金，月缴存额以**职工本人当月工资**为基数。（《条例》第十七条）

### 2.3 缴存比例下限

职工和单位住房公积金的缴存比例均**不得低于**职工上一年度月平均工资的**5%**。有条件的城市，可以适当提高缴存比例。具体缴存比例由住房公积金管理委员会拟订，经本级人民政府审核后，报省、自治区、直辖市人民政府批准。（《条例》第十八条）

### 2.4 基数与缴存比例的关系

缴存基数是确定缴存比例的前提条件。**缴存比例**的适用需要以**缴存基数**的确定为前提——即必须先确定缴存基数，再乘以相应的比例，方能计算出月缴存额。（来源：ent_缴存比例 → requires → ent_缴存基数）

## 三、适用条件

### 3.1 适用主体

缴存基数适用于以下缴存主体：

| 主体 | 基数确定方式 | 依据 |
|------|-------------|------|
| 在职职工（单位缴存） | 上一年度月平均工资 | 《条例》第十六条 |
| 新参加工作职工 | 当月工资 | 《条例》第十七条 |
| 新调入职工 | 当月工资 | 《条例》第十七条 |
| 灵活就业人员（自愿缴存） | 参照约定基数 | 地方规定 |

### 3.2 前置条件

缴存基数的确定需以下前置条件已满足：

1. **缴存职工**已建立住房公积金账户（《条例》第十三条、第十五条）
2. **缴存单位**已办理住房公积金缴存登记（《条例》第十三条、第十四条）
3. 单位与职工之间存在劳动关系或符合缴存资格

### 3.3 关联关系

- **缴存基数 → requires（要求） → 缴存职工**：缴存基数须以缴存职工的存续为前提，缴存职工的个人信息是基数核定的基础。
- **缴存比例 → requires（要求） → 缴存基数**：缴存比例的计算需要以缴存基数为参照。
- **缴存单位 → requires（要求） → 缴存基数**：单位为职工办理缴存登记时须同步核定缴存基数。
- **在职职工 → requires（要求） → 缴存基数**：在职职工属于应缴人群，其缴存义务以基数计算。
- **灵活就业人员 → requires（要求） → 缴存基数**：灵活就业人员自愿参加公积金制度亦需确定缴存基数。
