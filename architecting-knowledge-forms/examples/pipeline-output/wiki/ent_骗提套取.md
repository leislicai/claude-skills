# 骗提套取

## 概述

骗提套取是指缴存职工通过虚构住房消费行为、提供虚假证明材料或利用制度漏洞等不正当手段，违规提取或套取住房公积金账户内存储余额的行为。骗提套取行为严重违反《住房公积金管理条例》（国务院令第262号）第五条规定——住房公积金应当用于职工购买、建造、翻建、大修自住住房，任何单位和个人不得挪作他用。（kb_001）

骗提套取的治理依据为住房城乡建设部、财政部、人民银行、公安部联合发布的《关于开展治理违规提取住房公积金工作的通知》（建金〔2018〕46号）。该通知针对住房公积金提取环节中的欺诈行为，系统规定了优化审核流程、实施失信联合惩戒、建立跨地协查机制、集中开展治理工作、广泛开展宣传引导五项治理措施。（kb_013, kb_014, kb_015, kb_016, kb_017）

骗提套取治理的核心目标：保护住房公积金资金安全，维护住房公积金制度的公平性和可持续性，保障全体缴存职工的合法权益。

## 核心标准

### 可疑情形的识别标准

根据《关于开展治理违规提取住房公积金工作的通知》规定，以下情形属于需严格审核住房消费行为和证明材料真实性的可疑情形：（kb_013）

1. **同一人多次变更婚姻关系购房**——指申请提取人在短期内多次办理结婚、离婚登记，通过婚姻关系变更获取多人购房资格以提取住房公积金。
2. **多人频繁买卖同一套住房**——指同一套住房在短期内被多次交易，每次交易均伴随住房公积金提取申请。
3. **异地购房尤其是非户籍地非缴存地购房**——指购房所在地既非提取申请人户籍所在地，也非其住房公积金缴存所在地。
4. **非配偶或非直系亲属共同购房**——指购房人与共同购房人之间不具有配偶关系或直系亲属关系。

### 审核流程标准

住房公积金管理中心对提取申请进行审核时，应当区分以下两种情形分别适用审核时限：（kb_013）

- **材料齐全的**：审核无误后应当即时办理。
- **需进一步核查的**：应当在受理提取申请之日起3个工作日内办结。核查范围包括申请人异地房产交易记录、不动产登记信息、户籍信息等。

### 失信认定与惩戒标准

对骗提套取行为的失信惩戒分三个梯度：（kb_014）

1. **一般违规**——记载失信记录，并随个人住房公积金账户一并转移至新缴存地（如涉及账户转移）。
2. **已提取资金的**——责令限期全额退回，并在一定期限内限制其住房公积金提取和贷款申请。
3. **严重失信**（逾期仍不退回的）——列为严重失信行为，依法依规向相关管理部门报送失信信息，实施跨部门联合惩戒。机关、事业单位及国有企业缴存职工违规提取情节严重的，通报其所在单位。

### 跨地协查标准

住房公积金管理中心进行提取业务审核时，需核查申请人异地房产交易、不动产登记、户籍等信息的，可商请信息产生地住房公积金管理中心向相关信息管理部门代为核查。信息产生地住房公积金管理中心应当及时核查信息并反馈结果。（kb_015）

### 联合治理标准

住房公积金管理中心应当主动协调当地公安、通信、城管、网信等部门，集中开展治理工作：（kb_016）

- 全面清理违规提取住房公积金的有关信息；
- 依法关停发布违规提取住房公积金信息的网站和涉嫌违法电话；
- 对违规提取住房公积金的中介机构和其他组织，依法予以查处；
- 对涉嫌伪造及使用购房合同、发票、不动产权证书、结婚证等虚假证明材料的组织和个人，及时向公安等部门移交问题线索，严肃依法惩治。

### 单位核实义务

职工提取住房公积金账户内的存储余额的，所在单位应当予以核实，并出具提取证明。职工应当持提取证明向住房公积金管理中心申请提取住房公积金。（kb_007）

## 适用条件

### 适用范围对象

骗提套取的治理适用于以下主体：（kb_014）

- **缴存职工**——各类用人单位（国家机关、国有企业、城镇集体企业、外商投资企业、城镇私营企业及其他城镇企业、事业单位、民办非企业单位、社会团体）的在职缴存职工。（kb_001, kb_002）
- **中介机构和其他组织**——为骗提套取提供服务的第三方机构。（kb_016）
- **提供虚假证明材料的组织和个人**——伪造或使用虚假购房合同、发票、不动产权证书、结婚证等。（kb_016）

### 触发严格审核的情形

在提取申请审核中，以下情形自动触发严格审核程序：

- 申请提取金额显著超出常规标准的；
- 购房交易时间与申请提取时间间隔过近的；
- 提取申请材料存在疑点或无法通过常规渠道核实真实性的；
- 申请人近期存在多次提取记录的；
- 申请人存在既往失信记录的。

### 区域重点防控

人员跨地区流动频繁的城市群，应当率先建立更加紧密的信息协查机制，共同防控违规提取住房公积金行为。重点区域包括：（kb_015）

- 京津冀城市群
- 长三角城市群
- 珠三角城市群

## 相关依据

### 法律依据

1. **《住房公积金管理条例》**（1999年4月3日中华人民共和国国务院令第262号发布，根据2002年3月24日《国务院关于修改〈住房公积金管理条例〉的决定》第一次修订，根据2019年3月24日《国务院关于修改部分行政法规的决定》第二次修订）
   - 第五条：公积金用途限制——应当用于职工购买、建造、翻建、大修自住住房，不得挪作他用。（kb_001）
   - 第二十四条：可提取的六种法定情形。（kb_007）
   - 第二十五条：提取审核的程序要求和3日决定时限。（kb_007）
   - 第三十四条至三十六条：监督机制，包括单位和职工的查询权、复核权、揭发检举控告权。（kb_009）

### 政策文件

2. **住房城乡建设部、财政部、人民银行、公安部《关于开展治理违规提取住房公积金工作的通知》**（建金〔2018〕46号）——构成骗提套取治理的专项文件依据，规定优化提取审核流程、实施失信联合惩戒、建立跨地协查机制、集中开展治理工作、广泛开展宣传引导五项措施。（kb_013, kb_014, kb_015, kb_016, kb_017）

### 关联实体

3. **住房公积金提取**——骗提套取行为发生于住房公积金提取环节，提取规则是判定行为是否合规的基础标准。（ent_住房公积金提取, relation: requires）

4. **住房公积金管理中心**——作为提取审批和违规治理的执行主体，负责审核提取申请、实施失信惩戒、组织联合治理。（ent_住房公积金管理中心, relations: requires）

5. **住房公积金管理委员会**——作为住房公积金管理的决策机构，对提取政策调整、治理方案审批等事项拥有决定权。（ent_住房公积金管理委员会）
