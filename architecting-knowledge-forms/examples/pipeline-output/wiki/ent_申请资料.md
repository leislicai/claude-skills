# 申请资料

## 概述

申请资料是指办理住房公积金各项业务（缴存登记、账户设立、提取、贷款等）时，单位或个人必须向住房公积金管理中心或受委托银行提交的法定证明材料。根据《住房公积金管理条例》及天水市相关业务规程，申请资料的完整性和真实性是业务办理的前提条件。不同类型业务所需资料各有差异，但均要求提供原件或加盖公章的复印件。

## 核心标准

### 一、单位缴存登记及账户设立资料

**新设立单位缴存登记材料：**
- 单位证照（营业执照、统一社会信用代码证书等）
- 法定代表人身份证件
- 经办人身份证件
- 单位缴存登记申请表

**个人账户设立材料：**
- 《住房公积金个人账户设立清册》
- 职工身份证明
- 单位应在缴存登记后20日内为职工开户
- 新录用或调入职工30日内开户

### 二、提取业务申请资料

**基本材料（各类提取通用）：**
- 身份证原件
- 申请人本人银行借记卡
- 婚姻关系证明（配偶提取时提供）

**购买自住住房提取：**
- 商品房：经备案的购房合同 + 付款凭证，或不动产权证书 + 购房发票
- 再交易住房（二手房）：已过户的不动产权证书 + 税务票据
- 经济适用房/单位集资建房：相关批文及购房协议
- 拆迁安置房：拆迁证明 + 补偿安置合同
- 保障性住房：视同商品房办理

**建造、翻建、大修自住住房提取：**
- 建造/翻建：土地证 + 规划许可证 + 建材费用凭证
- 大修：C级或D级房屋安全鉴定报告 + 施工合同及费用凭证
- 加装电梯：不动产权证书 + 加装电梯协议书/合同 + 验收证明 + 费用发票及分摊方案

**偿还购房贷款本息提取：**
- 商业贷款：借款合同 + 近12个月还款明细
- 公积金贷款：通过系统核验（无需额外材料）
- 对冲还贷：身份证（本中心贷款）

**租赁住房提取：**
- 连续缴存满3个月证明
- 本地无房证明
- 公共租赁住房：租赁合同及租金证明

**离休、退休提取：**
- 未达法定退休年龄：离休证/退休证
- 已达法定退休年龄（男60岁/女55岁）：凭身份证直接办理

**死亡销户提取：**
- 死亡证明
- 继承权/受遗赠权证明文件

**解除劳动关系提取：**
- 封存满半年后办理（封存6个月以上可线上办理免材料）

### 三、贷款业务申请资料

**住房公积金贷款基本材料：**
- 身份证（借款人及配偶）
- 婚姻状况证明
- 收入证明
- 个人信用报告
- 首付款证明
- 购房合同
- 不动产套数证明（缴存地、购房地、户籍地三地）
- 担保材料（抵押、质押或保证联保）

**异地贷款额外材料：**
- 异地贷款职工住房公积金缴存及使用证明
- 近6个月缴存明细
- 异地缴存户另需提供天水市现房作为抵押

### 四、组合贷款申请资料

- 同时满足公积金中心和商贷银行的各项条件要求
- 公积金贷款与商业贷款分别审批，资料共享避免重复提交
- 抵押登记由中心与商贷银行共同申请，同为第一顺位抵押权人

## 适用条件

1. **真实性原则**：申请人须以真实合规材料申请公积金业务，严禁伪造材料或勾结中介虚假交易。违规行为将严肃查处并联合惩戒，构成犯罪的移送司法。

2. **完整性原则**：申请材料齐全、信息真实有效的，审核无误后应即时办理；需对申请材料进一步核查的，应在受理申请之日起3个工作日内办结。

3. **材料替代规则**：部分业务可通过系统自动核验替代纸质材料，如公积金贷款还款记录、已达法定退休年龄的退休提取等。

4. **身份核验**：个人办理须提供身份证原件；代办须提供委托人及代办人身份证件及授权委托书。

5. **原价优先**：申请资料原则上需提供原件；单位证照、审批文件、法人身份证等不能提供原件时，可使用加盖公章的复印件视同原件。

## 相关依据

1. **《住房公积金管理条例》**（国务院令第262号，1999年发布，2002年、2019年两次修订）
   - 第十三条：单位办理缴存登记及账户设立
   - 第二十四条至第二十五条：提取条件及流程
   - 第二十六条至第二十七条：贷款申请及担保

2. **《住房城乡建设部 财政部 人民银行 公安部 关于开展治理违规提取住房公积金工作的通知》**
   - 优化提取审核流程，简化材料要求
   - 对多次变更婚姻关系购房、频繁买卖同一套房、异地购房等可疑情形加强审核

3. **《天水市住房公积金归集管理办法》**
   - 缴存登记及账户设立所需材料
   - 月缴存额核定及变更材料

4. **《天水市住房公积金归集业务操作规程（试行）》**
   - 单位账户设立（第5条）：申请资料及办理时限
   - 个人账户设立（第6条）：开户清册及办理时限
   - 缴存基数核定（第7条）：基数调整清册

5. **《天水市住房公积金提取业务操作规程（试行）》**
   - 基本材料要求（身份证、银行卡）
   - 各类提取情形的差异化材料清单

6. **《天水市住房公积金个人住房贷款管理办法》**
   - 贷款申请条件及所需材料
   - 贷款额度、期限、利率相关材料
