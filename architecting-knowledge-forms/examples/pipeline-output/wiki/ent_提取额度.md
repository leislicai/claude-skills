# 提取额度

> 实体类型：clause  
> 关联实体：[[ent_住房公积金提取]] (part_of)  
> 来源块数：15  
> 最后更新：2026-06-15

## 概述

提取额度是指缴存职工在符合住房公积金提取条件时，可以从本人住房公积金账户中提取的资金上限。提取额度根据提取用途、账户余额及相关政策规定确定，不同提取情形适用不同的额度标准。

---

## 核心标准

### 一、一般提取额度

- 缴存职工提取住房公积金的，提取金额不得超过职工住房公积金账户内的存储余额（依据：住房公积金管理条例 第二十四条）。
- 提取申请材料齐全、审核无误的，应即时办理；需进一步核查的，应在受理提取申请之日起 3 个工作日内办结（依据：住房城乡建设部等四部门《关于开展治理违规提取住房公积金工作的通知》第二项）。

### 二、销户提取额度

以下情形提取住房公积金的，应当提取全部存储余额并同时注销职工住房公积金账户（依据：住房公积金管理条例 第二十四条第二款）：

1. **离休、退休**
2. **完全丧失劳动能力，并与单位终止劳动关系**
3. **出境定居**

### 三、死亡提取额度

- 职工死亡或者被宣告死亡的，其继承人、受遗赠人可以提取职工住房公积金账户内的全部存储余额。
- 无继承人也无受遗赠人的，职工住房公积金账户内的存储余额纳入住房公积金的增值收益。（依据：住房公积金管理条例 第二十四条第三款）

### 四、偿还购房贷款提取额度

- 偿还购房贷款本息的，可提取额度原则上不超过当期应还贷款本息总额。
- 已办理月对冲还贷业务的，由委托银行按月划扣还贷（依据：相关操作规程）。

### 五、租赁提取额度

- 房租超出家庭工资收入规定比例的，可提取超出部分对应的住房公积金。
- 具体额度上限由各城市住房公积金管理委员会根据当地租金水平和收入水平确定。

---

## 适用条件

提取额度适用的前提是符合住房公积金提取条件。根据住房公积金管理条例第二十四条，职工有下列情形之一的，可以提取住房公积金账户内的存储余额：

1. 购买、建造、翻建、大修自住住房的；
2. 离休、退休的；
3. 完全丧失劳动能力，并与单位终止劳动关系的；
4. 出境定居的；
5. 偿还购房贷款本息的；
6. 房租超出家庭工资收入的规定比例的；

在以上任一条件满足的情况下，按照对应的标准确定提取额度。

## 办理材料

提取额度审核所需基础材料（依据：住房公积金管理条例第二十五条及相关操作规程）：

- **提取证明**：所在单位出具的核实证明
- **身份证明**：职工本人有效身份证件
- **分类补充材料**（按提取类型提供）：
  - 购买自住住房：购房合同、不动产权证书、购房发票等
  - 偿还贷款本息：借款合同、还款明细等
  - 租赁住房：租赁合同、租金发票、家庭收入证明等
  - 离休/退休：退休证或相关审批文件
  - 完全丧失劳动能力：劳动能力鉴定证明、终止劳动关系证明
  - 出境定居：出境定居审批证明
  - 死亡提取：死亡证明、继承权公证书或遗赠证明

> 材料齐全且审核无误的应即时办理；对材料存疑的，住房公积金管理中心有权进一步核查。

## 办理流程

提取额度审核流程如下（综合住房公积金管理条例第二十五条和优化审核流程规定）：

```
┌─────────────────────────────────────────┐
│ ① 单位核实并出具提取证明                 │
├─────────────────────────────────────────┤
│ ② 职工持提取证明向公积金中心提出申请       │
├─────────────────────────────────────────┤
│ ③ 公积金中心受理审核                      │
├─────────────────────────────────────────┤
│ ④ 准予提取 → 受委托银行办理支付手续        │
│ ⑤ 不准提取 → 通知申请人并说明理由          │
└─────────────────────────────────────────┘
```

**审核时限**：

- 材料齐全、审核无误的：**即时办理**
- 需进一步核查的：**3 个工作日内**办结
- 准予提取的由受委托银行办理支付手续（依据：住房公积金管理条例第二十五条）

**特殊情形加强审核**：

对以下情形，要严格审核住房消费行为和证明材料的真实性（依据：治理违规提取通知第二项）：
- 同一人多次变更婚姻关系购房
- 多人频繁买卖同一套住房
- 异地购房（特别是非户籍地、非缴存地购房）
- 非配偶或非直系亲属共同购房

**失信惩戒**（依据：治理违规提取通知第三项）：
- 违规提取的记入失信记录，随个人账户一并转移
- 已提取资金的，责令限期全额退回，并限制后续提取和贷款
- 逾期仍不退回的，列为严重失信行为，实施跨部门联合惩戒
