# 住房公积金个人住房贷款

## 概述

住房公积金个人住房贷款是指缴存住房公积金的职工，在购买、建造、翻建、大修自住住房时，向住房公积金管理中心申请的专项贷款。根据《住房公积金管理条例》第二十六条规定，缴存住房公积金的职工在符合条件时可申请贷款，住房公积金管理中心应当自受理申请之日起15日内作出准予贷款或者不准贷款的决定。住房公积金贷款的风险，由住房公积金管理中心承担。

## 核心标准

### 一、贷款对象与条件

**基本条件：**
- 缴存住房公积金的职工（含本地和异地缴存职工）
- 连续足额缴存住房公积金**6个月以上**
- 信用良好，征信违约不超连续3期或累计6期
- 具有完全民事行为能力
- 有稳定的经济收入和偿还贷款本息的能力
- 提供符合要求的担保

**住房套数认定（认房又认贷）：**
- 首套房：无住房且无公积金贷款记录
- 二套房：已使用一次公积金贷款且已结清、本市无住房的，再次申请按首套房执行；有住房记录或贷款记录的按规定执行
- 限制购买第三套住房

**不予贷款情形：**
- 存在严重逾期记录
- 被列入失信名单
- 有骗提骗贷行为记录
- 提供虚假证明材料
- 购买非自住住房（商业用房等）
- 未落实担保
- 其他不符合公积金管理规定的情形

### 二、贷款额度

贷款额度受以下五重限制，取最低值：

| 限制因素 | 具体规则 |
|---------|---------|
| 账户余额倍数 | 贷款额 ≤ 公积金缴存余额 × 规定倍数（天水曾执行15-18倍） |
| 房价比例 | 首套最高房总价**70%**，二套最高**60%** |
| 还款能力 | 月还款额不超过月收入的**50%-60%** |
| 最高限额 | 天水两区最高**60万元**、五县最高**50万元** |
| 其他因素 | 担保方式、贷款用途等 |

**共同借款人规则：** 允许单身或单方缴存职工的直系亲属（父母）作为共同借款人，可办理月对冲，不计算父母名下房屋套数，账户余额合并计算。

### 三、贷款利率与期限

**利率标准：**
- 按中国人民银行规定的住房公积金贷款利率执行
- 二套房贷款利率不低于首套房的**1.1倍**
- 贷款期限在一年以内的，遇利率调整不调整
- 贷款期限在一年以上的，遇利率调整于**次年1月1日**起按新利率执行

**贷款期限：**
- 最长**30年**
- 联保贷款最长**20年**
- 具体以借款合同约定为准

**还款方式：**
- 等额本息
- 等额本金

### 四、贷款流程

**申请与受理：**
1. 借款人向住房公积金管理中心或受委托银行提交贷款申请资料
2. 受托银行收齐资料后报送中心预审批
3. 预审批通过后录入信息、扫描证明和资料原件

**审核与审批：**
1. 贷前调查：中心和银行分别调查贷款用途、资料真实性、抵押物状况、还款能力、征信、婚姻等
2. 面谈面签：告知贷款流程，借款人及配偶填写资料并签署合同
3. 住房公积金管理中心自受理申请之日起**15日内**作出准予贷款或者不准贷款的决定
4. 通知申请人；准予贷款的，由受委托银行办理贷款手续

**担保与放款：**
1. 申请人申请住房公积金贷款的，应当提供担保（抵押、质押或保证联保）
2. 借款合同和抵押合同生效后，贷款银行将资金划转至售房单位账户
3. 抵押登记完成后**3个工作日内**放款

### 五、贷款偿还

**正常还款：**
- 借款人按月将还款本息存入还款账户
- 资金回收顺序：正常还贷按利息→本金
- 逾期按罚息→逾期利息→逾期本金
- 提前还款按利息→本金

**逾期处理：**
- 违约时受托银行负责催收
- 连续3个月以上违约发放催收通知书
- 连续6个月以上违约，中心有权起诉并强制划转借款人及配偶的公积金用于还款

**月对冲还贷：**
- 符合条件的借款人可与中心签订协议，以每月缴存的公积金直接冲抵贷款本息
- 需携带身份证就近前往公积金大厅办理开通手续

### 六、异地贷款

- 异地缴存职工在天水购房可申请公积金贷款，无缴存地、户籍地限制，与本地职工同等权益
- 需提供异地贷款职工住房公积金缴存及使用证明、近6个月缴存明细
- 非天水缴存职工需提供天水市现房作为抵押
- 借款人正常缴存且配偶异地缴存的，贷款金额可合并计算

## 适用条件

1. **贷款用途限制**：住房公积金贷款仅用于购买、建造、翻建、大修自住住房，不得挪作他用。

2. **担保要求**：申请人申请住房公积金贷款的，应当提供担保。担保方式包括抵押、质押和保证联保。

3. **贷款风险承担**：住房公积金贷款的风险由住房公积金管理中心承担。

4. **贷款结清**：还清全部贷款本息后，借款合同终止，抵押登记注销。

5. **流动性风险管控**：当个贷率超过风险警戒线（如85%），可启动流动性风险预警，采取贷款额度打折、暂停月对冲签约、轮候发放等措施。

## 相关依据

1. **《住房公积金管理条例》**（国务院令第262号）
   - 第二十六条：贷款申请及审批
   - 第二十七条：贷款担保
   - 第八条至第十二条：管理机构和职责

2. **《天水市住房公积金个人住房贷款管理办法》**
   - 贷款对象和条件（含异地贷款）
   - 贷款额度、期限和利率
   - 贷款程序（申请→受理→评估→审批→签约→担保→放款）
   - 贷款担保（抵押、质押、保证联保）
   - 合同变更与终止
   - 贷后管理与违约处理

3. **天水市住房公积金管理中心相关贷款政策调整通知**
   - 优化调整住房公积金个人住房贷款政策（首付比例、贷款额度、共同借款人等）
   - 流动性风险预警管理办法
   - 月对冲还贷业务规定

4. **《天水市住房公积金个人住房异地贷款实施细则》**
   - 异地贷款申请条件
   - 异地贷款所需资料
   - 贷款审核审批流程

5. **《天水市住房公积金提取管理办法（试行）》**（贷款偿还提取相关内容）
