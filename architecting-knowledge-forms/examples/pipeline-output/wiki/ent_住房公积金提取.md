# 住房公积金提取

## 概述

住房公积金提取是指缴存职工依据《住房公积金管理条例》（国务院令第262号，2002年、2019年两次修订）第二十四条规定，在符合法定情形时，向住房公积金管理中心申请提取本人住房公积金账户内存储余额的行政服务行为。住房公积金提取是住房公积金制度的核心使用环节之一，属于缴存职工的基本权益。（kb_001, kb_007）

住房公积金提取的管理运作遵循"住房公积金管理委员会决策、住房公积金管理中心运作、银行专户存储、财政监督"的原则。住房公积金管理中心负责审批住房公积金的提取、使用，受委托银行办理支付手续。（kb_001, kb_003）

根据住房城乡建设部、财政部、人民银行、公安部《关于开展治理违规提取住房公积金工作的通知》（建金〔2018〕46号）要求，各地应优化提取审核流程，积极推行网上办理，同时严格审核可疑情形，实施失信联合惩戒。（kb_013, kb_014）

**上位法依据：** 《住房公积金管理条例》（国务院令第262号，1999年4月发布，2019年3月最新修订）第四章"提取和使用"第二十四至二十五条。（kb_001, kb_007）

**政策文件依据：** 住房城乡建设部、财政部、人民银行、公安部《关于开展治理违规提取住房公积金工作的通知》。（kb_013, kb_014, kb_015, kb_016）

**已废止文件：** 天公积金发〔2020〕53号文件（天水市住房公积金管理中心关于完善住房公积金个人住房贷款和提取服务的通知）已被本规程所替代。（relation: repeals）

## 办理流程

### 标准提取流程

根据《住房公积金管理条例》第二十五条规定，提取流程如下：

1. **单位核实并出具提取证明**：职工提取住房公积金账户内的存储余额的，所在单位应当予以核实，并出具提取证明。（kb_007）
2. **提交申请**：职工持提取证明向住房公积金管理中心申请提取住房公积金。（kb_007）
3. **审核决定**：住房公积金管理中心应当自受理申请之日起3日内作出准予提取或者不准提取的决定，并通知申请人。（kb_007）
4. **银行支付**：准予提取的，由受委托银行办理支付手续。（kb_007）

### 审核时限优化

根据《关于开展治理违规提取住房公积金工作的通知》的优化要求：

- **材料齐全即时办理**：缴存职工提取申请材料齐全的，审核无误后应即时办理。（kb_013）
- **需进一步核查的**：应在受理提取申请之日起3个工作日内办结。（kb_013）

以上时限规定在原有3日决定期基础上，进一步细化为"即时办理"和"3个工作日"两档，缩短了审核周期。

### 网上办理方式

积极开展提取住房公积金业务网上咨询，大力推行网上审核和业务办理，缩短审核时限。（kb_013）

### 特殊情形的严格审核

对以下申请提取住房公积金的，要严格审核住房消费行为和证明材料的真实性：（kb_013）
- 同一人多次变更婚姻关系购房的；
- 多人频繁买卖同一套住房的；
- 异地购房尤其是非户籍地非缴存地购房的；
- 非配偶或非直系亲属共同购房的。

### 跨地协查机制

住房公积金管理中心进行提取业务审核，需核查申请人异地房产交易、不动产登记、户籍等相关信息的，可商请信息产生地住房公积金管理中心向相关信息管理部门代为核查。信息产生地住房公积金管理中心应当及时核查信息并反馈结果。京津冀、长三角、珠三角等城市群应当率先建立更加紧密的信息协查机制。（kb_015）

### 违规提取的治理与惩戒

住房公积金管理中心协调当地公安、通信、城管、网信等部门，集中开展治理违规提取住房公积金工作，全面清理违规提取信息，依法关停发布违规提取信息的网站和涉嫌违法电话，查处违规中介机构，对涉嫌伪造及使用虚假证明材料的行为移交公安部门依法惩治。（kb_016）

### 销户提取情形

依照以下情形提取住房公积金的，应当同时注销职工住房公积金账户：（kb_007）
- 离休、退休的；
- 完全丧失劳动能力，并与单位终止劳动关系的；
- 出境定居的。

### 继承提取

职工死亡或者被宣告死亡的，职工的继承人、受遗赠人可以提取职工住房公积金账户内的存储余额；无继承人也无受遗赠人的，职工住房公积金账户内的存储余额纳入住房公积金的增值收益。（kb_007）

## 适用条件

### 提取情形

职工有下列情形之一的，可以提取职工住房公积金账户内的存储余额：（kb_007）

1. **购买、建造、翻建、大修自住住房的** ——指缴存职工为满足家庭居住需要，购买、建造、翻建或大修自有产权住房的情形。需符合自住住房认定标准。（kb_002, kb_003, kb_004, kb_005, kb_006, kb_007, kb_008）
2. **离休、退休的** ——职工已办理离休或退休手续，不再保留劳动关系的情形。
3. **完全丧失劳动能力，并与单位终止劳动关系的** ——经劳动能力鉴定机构鉴定为完全丧失劳动能力，且与原单位已解除或终止劳动关系。
4. **出境定居的** ——职工移居境外（含港澳台地区），不再保留国内户籍或常住资格。
5. **偿还购房贷款本息的** ——职工在偿还自住住房购房贷款期间，可按年度或分次提取。
6. **房租超出家庭工资收入的规定比例的** ——职工租赁自住住房，月租金超出家庭月工资收入规定比例的。

### 前置条件

提取住房公积金须满足以下前置条件：（relations: requires）
- **缴存住房公积金账户**：申请人必须为正常缴存住房公积金的职工，拥有有效的住房公积金账户。（ent_住房公积金账户, relations: requires）
- **自住住房**：提取事由涉及的房屋须为自住住房（购买、建造、翻建、大修、偿还贷款、租赁等情形均要求与自住住房相关）。（ent_自住住房, relations: requires）
- **提取材料**：按照申请情形提供完整的提取证明材料。（ent_提取材料, relations: requires）

### 监督保障

职工、单位有权查询本人、本单位住房公积金的缴存、提取情况，住房公积金管理中心、受委托银行不得拒绝。职工、单位对住房公积金账户内的存储余额有异议的，可以申请受委托银行复核；对复核结果有异议的，可以申请住房公积金管理中心重新复核。受委托银行、住房公积金管理中心应当自收到申请之日起5日内给予书面答复。职工有权揭发、检举、控告挪用住房公积金的行为。（kb_009）

### 违规后果

对违规提取住房公积金的缴存职工：（kb_014）
- 记入失信记录，并随个人账户一并转移；
- 已提取资金的，责令限期全额退回，在一定期限内限制其住房公积金提取和贷款；
- 逾期仍不退回的，列为严重失信行为，依法依规向相关管理部门报送失信信息，实施联合惩戒；
- 机关、事业单位及国有企业缴存职工违规提取住房公积金情节严重的，向其所在单位通报。

## 办理材料

### 基础材料

根据《住房公积金管理条例》第二十五条规定，提取住房公积金须提供：（kb_007）
- **提取证明**（所在单位核实后出具）；
- 其他根据提取情形所需的证明文件。

### 按情形的材料说明

不同提取情形所需材料有所不同，通常包括以下类别：

| 提取情形 | 主要材料 |
|----------|---------|
| 购买自住住房 | 购房合同、不动产权证书、购房发票等 |
| 建造、翻建、大修自住住房 | 规划许可证、建设工程许可证、费用票据等 |
| 离休、退休 | 离休证、退休证或人事部门出具的退休审批文件 |
| 完全丧失劳动能力并与单位终止劳动关系 | 伤残鉴定证明、解除劳动关系证明 |
| 出境定居 | 出境定居证明、户籍注销证明 |
| 偿还购房贷款本息 | 贷款合同、还款明细、贷款余额证明 |
| 房租超标 | 房屋租赁合同、租金发票、家庭收入证明 |
| 继承提取 | 死亡证明、继承权公证书、继承人或受遗赠人身份证件 |

（kb_004, kb_005, kb_006, kb_007, kb_008, kb_009 对提取材料有涉及；ent_提取材料 relations: requires）

> 注：具体材料清单以当地住房公积金管理中心发布的业务规程为准，各地在国务院条例基础上可能有细化要求。

### 材料真实性审核

住房公积金管理中心对提取申请材料的真实性进行核查。对涉嫌伪造及使用购房合同、发票、不动产权证书、结婚证等虚假证明材料的组织和个人，依法严肃惩治。（kb_016）

## 相关依据

### 法律依据

1. **《住房公积金管理条例》**（1999年4月3日中华人民共和国国务院令第262号发布，根据2002年3月24日《国务院关于修改〈住房公积金管理条例〉的决定》第一次修订，根据2019年3月24日《国务院关于修改部分行政法规的决定》第二次修订）——共七章四十七条，规定住房公积金的缴存、提取、使用、管理和监督。其中，第四章"提取和使用"（第二十四至二十五条）为住房公积金提取的直接法律依据。（kb_001—kb_012）

### 政策文件

2. **住房城乡建设部、财政部、人民银行、公安部《关于开展治理违规提取住房公积金工作的通知》**（建金〔2018〕46号）——规定优化提取审核流程、实施失信联合惩戒、建立跨地协查机制、集中开展治理工作等措施。（kb_013—kb_016）

### 关联实体

3. **《住房公积金提取条例》上位依据**——提取住房公积金的法律依据为国务院令第262号，本地管理中心在提取审批中须遵照执行。（ent_住房公积金管理条例, relation: references）

4. **住房公积金提取是住房公积金制度的一部分**——提取环节是住房公积金"缴存-提取-贷款"三大核心业务之一。（ent_住房公积金, relation: part_of）

5. **前置依赖实体**
   - **住房公积金账户**：提取须以有效账户为基础。（ent_住房公积金账户, relation: requires）
   - **提取材料**：提取须提交相应证明材料。（ent_提取材料, relation: requires）
   - **自住住房**：多数提取情形均以自住住房为标的。（ent_自住住房, relation: requires）
